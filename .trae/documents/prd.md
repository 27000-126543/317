## 1. 产品概述

绿循 — 大型综合环保回收与循环利用平台，通过数字化手段连接居民、回收员、志愿者和管理员，实现废品回收全流程线上化，推动社区绿色循环经济。

- 目标用户：城市居民（废品出售方）、回收员（服务提供方）、社区志愿者（活动参与方）、平台管理员（运营管理方）
- 核心价值：便捷预约上门回收 → 智能积分激励 → 商城兑换闭环 → 社区活动促活 → 数据驱动运营

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 手机号注册 | 预约回收、查看积分、商城兑换、参与社区活动、会员体系 |
| 回收员 | 手机号注册+资质审核 | 接单、扫码确认、称重拍照、查看绩效、实时定位 |
| 志愿者 | 手机号注册 | 参与社区活动、扫码签到、获取参与积分 |
| 管理员 | 后台授权 | 数据看板、运营报表、价格调整、人员配置、投诉处理 |

### 2.2 功能模块

1. **首页**: 回收品类入口、快捷预约、积分概览、社区活动推荐、环保资讯
2. **预约回收页**: 品类选择、地址填写、时间预约、预估重量、订单状态跟踪
3. **回收员工作台**: 待接订单、进行中订单、实时定位、扫码确认、称重拍照
4. **积分商城**: 商品分类浏览、积分兑换、物流跟踪、兑换记录
5. **社区活动页**: 活动列表、发起活动、志愿者推荐、扫码签到、活动详情
6. **会员中心**: 等级展示、升级进度、权益说明、累计数据、礼遇通知
7. **管理看板**: 实时数据、品类回收量、订单量、回收员活跃度、积分兑换率、投诉处理时效、预测建议、报表导出

## 3. 核心流程

### 3.1 预约回收流程
用户选择品类和填写地址后，系统自动匹配最近回收员并推送接单通知。回收员接单后上门，扫码确认订单，拍照称重后系统根据品类和重量自动计算积分发放到用户账户。

```mermaid
flowchart TD
    "用户预约回收" --> "选择品类/填写地址/预约时间"
    "选择品类/填写地址/预约时间" --> "系统匹配最近回收员"
    "系统匹配最近回收员" --> "推送接单通知"
    "推送接单通知" --> "回收员接单"
    "回收员接单" --> "回收员上门"
    "回收员上门" --> "扫码确认订单"
    "扫码确认订单" --> "拍照称重"
    "拍照称重" --> "系统自动计算积分"
    "系统自动计算积分" --> "积分发放到用户账户"
    "积分发放到用户账户" --> "订单完成"
```

### 3.2 积分兑换流程
用户在商城选择商品后确认兑换，系统扣除积分并自动生成物流单，推送取货通知给用户。

```mermaid
flowchart TD
    "用户浏览商城" --> "选择商品"
    "选择商品" --> "确认兑换（扣除积分）"
    "确认兑换（扣除积分）" --> "自动生成物流单"
    "自动生成物流单" --> "推送取货通知"
    "推送取货通知" --> "用户取货"
    "用户取货" --> "兑换完成"
```

### 3.3 社区活动流程
用户发起社区回收活动后，系统推荐附近志愿者并生成活动任务，活动当天扫码签到额外发放参与积分。

```mermaid
flowchart TD
    "用户发起社区活动" --> "填写活动信息"
    "填写活动信息" --> "系统推荐附近志愿者"
    "系统推荐附近志愿者" --> "生成活动任务"
    "生成活动任务" --> "志愿者报名参与"
    "志愿者报名参与" --> "活动当天扫码签到"
    "活动当天扫码签到" --> "额外发放参与积分"
    "额外发放参与积分" --> "活动结束统计"
```

### 3.4 会员升级流程
系统根据累计回收重量和活跃度自动计算会员等级，升级时推送礼遇通知。

```mermaid
flowchart TD
    "用户完成回收" --> "累计回收重量+活跃度计算"
    "累计回收重量+活跃度计算" --> "达到升级条件"
    "达到升级条件" --> "自动升级会员等级"
    "自动升级会员等级" --> "推送礼遇通知"
    "推送礼遇通知" --> "解锁新权益"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：森林绿(#2D6A4F) + 明亮黄绿(#95D5B2) 象征环保与循环
- 辅助色：暖橙(#F4A261)作为强调色用于积分和按钮
- 按钮风格：圆角胶囊按钮，主按钮带微渐变和阴影
- 字体：思源黑体(Noto Sans SC)标题 + 苹方(PingFang SC)正文
- 布局风格：卡片式布局，底部Tab导航，顶部状态栏
- 图标风格：线性图标搭配微渐变填充，自然元素（叶子、循环箭头）主题

### 4.3 响应式设计
- 桌面优先设计，适配1280px+宽度管理看板
- 平板适配768px-1024px，侧边栏可收起
- 移动端适配320px-768px，底部Tab导航，卡片单列布局
- 触摸优化：按钮最小44px点击区域，滑动操作反馈
